#### **III. Architecture & Design**
This critical phase translates the insights gleaned from discovery into a tangible future-state vision, providing the architectural blueprint for the migration.
*   **Professional Services**: The provision of expert consulting services for the **delivery of the target state architecture, comprehensive migration strategy, and detailed future state design**.
*   **Technical Design Document (TDD)**: A pivotal document presenting a **comprehensive architecture blueprint for the target GCP environment**. This includes crucial details on service selections, configurations, robust security considerations, and performance optimization strategies.

#### **IV. Code Conversion & Transformation**
This is the core modernization engine, focusing on the meticulous translation and adaptation of legacy Hadoop code to be fully compatible with GCP-native services.
*   **Code Components**: The delivery of **all code components developed during the migration activities**, ensuring a complete and functional set of translated logic.
*   **Raven Code Conversion**: Utilizing advanced automation, this deliverable encompasses the **conversion of in-scope tables, views, transformation jobs, and DAG components to GCP native components**. This includes, for instance, Hive table DDLs to GCP Native DDL and Presto/Spark SQL to GCP native, all adhering to mutually agreed-upon sharing locations (e.g., Git, GCS Buckets).
*   **Ad Hoc Query Support**: The provision of **converted ad hoc queries**, ensuring their full compatibility with BigQuery for ongoing operational and analytical needs.

#### **VIII. Testing & Validation**
A non-negotiable phase dedicated to verifying data integrity, functional correctness, and performance, thereby instilling confidence in the migrated environment.
*   **Pelican Licence**: The provision of a **subscription for the Pelican tool** for a specified duration (e.g., 4 months) to enable robust data validation and reconciliation between the legacy and target environments. The active engagement with Pelican for validation activities is a consistent theme.

#### **X. Post-Migration Support & Knowledge Transfer**
Ensuring long-term operational success and empowering client teams through comprehensive documentation and knowledge dissemination.
*   **Leading Practice and Recommendations Document**: A forward-looking document detailing **recommendations for next steps and leading practices** pertinent to the sustained success of the migrated environment.
*   **Technical Design Document (TDD)**: Beyond its role in design, the TDD serves as a fundamental artifact for **knowledge transfer**, providing a detailed reference for the implemented architecture and its operational nuances.
